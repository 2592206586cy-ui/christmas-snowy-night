# 圣诞雪夜 ❄️

一个纯 HTML 的圣诞雪夜小游戏/动态壁纸，无任何依赖，双击即玩。

## 文件

| 文件 | 说明 |
|---|---|
| `圣诞雪夜.html` | 🎮 游戏版：开铲车运雪堆雪人 |
| `圣诞雪夜壁纸.html` | 🖥 壁纸版：铲车自动巡逻堆雪人，适合 Plash / Wallpaper Engine 当动态壁纸 |

## 玩法（游戏版）

- **A D / ← →** 开铲车，铲斗自动收雪
- **空格 / ↑** 卸雪——把雪卸到小红旗旁的雪堆
- **两斗雪堆一个雪人**，堆满 **4 个雪人通关**
- **鼠标一笔画**心形 ❤ / 五角星 ⭐ / 圆圈 ⚪：区域内雪花会变成对应形状飘落
- **C** 重新开始
- 进度自动保存在浏览器里

## 壁纸版

无任何文字 UI，雪一直下，铲车自动铲雪堆雪人。macOS 上用 [Plash](https://apps.apple.com/app/plash/id1494023538)（免费）或 Steam 上的 Wallpaper Engine 加载即可。
